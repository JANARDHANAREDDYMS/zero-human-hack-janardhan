# Product name
CodeSensei interview preparation

## Description
A proposed interview-preparation service for students and early-career software engineers. It offers coding practice and mock interviews, then creates a personalized follow-up drill from the mistakes made in each mock interview. The selling point is: your next practice session starts where your last interview went wrong.

## Planned price
20 USD monthly

## Features
- 200 practice questions.
- Python, C++, Java and JavaScript support.
- Browser coding editor with code execution and test cases.
- Four 45-minute mock interviews per month.
- Feedback on correctness, complexity, communication and hints used.
- Topic completion tracking and session history.
- One free 15-minute sample interview.
- Personalized follow-up drills based on mistakes made in each mock interview.
- This is a proposed demo service, not a claim of an existing launched service.

## Research question
At 20 USD per month, which students and early-career software engineers would choose CodeSensei over existing interview-preparation tools, free resources or practicing on their own? Does personalized practice based on their mistakes give them a strong enough reason to switch or pay?

## Category
Professional service / coding interview preparation

## Audience
Students and early-career software engineers preparing for coding interviews.
